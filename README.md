# Rollout GP

**Build a self-steering racer like the real thing, let it go, and run after it through the city.**

Rollout GP is a browser game about the mini 4WD hobby: cars that run in walled lanes and turn by bouncing their rollers off the walls. You never steer. Every race is decided in the garage, and the drama happens alongside the car.

Live: https://rolloutgp.vercel.app
